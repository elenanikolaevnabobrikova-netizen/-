Перевод из десятичной в любую (через деление)

Последовательно делим число на основание новой системы. Делим до тех пор, пока очередное частное не станет меньше основания — оно станет старшей цифрой ответа. Остатки читаются снизу вверх.

Делимое ÷ Основание = Частное, остаток
... пока делимое ≥ основания
Ответ = последнее частное + остатки снизу вверх

Пример: 45 → двоичная

45 ÷ 2 = 22, остаток 1
22 ÷ 2 = 11, остаток 0
11 ÷ 2 =  5, остаток 1
 5 ÷ 2 =  2, остаток 1
 2 ÷ 2 =  1, остаток 0
1 < 2, останавливаемся.
Последнее частное = 1, остатки снизу вверх: 0,1,1,0,1
Ответ: 1011012

Перевод в десятичную (через разряды)

1. Нумеруем разряды справа налево, начиная с 0.
2. Находим вес каждого разряда: основаниеразряд.
3. Умножаем цифру на вес.
4. Складываем все значения.

Число = dn−1·qn−1 + … + d1·q1 + d0·q0

Пример: 1011₂ → десятичная

Разряды: 3, 2, 1, 0
Веса: 8, 4, 2, 1
Значения: 1·8 + 0·4 + 1·2 + 1·1 = 8+0+2+1
= 1110

Группировка битов: 2 ↔ 8, 2 ↔ 16

2 → 8: группируем биты справа налево по 3 (при необходимости слева дописываем нули). Каждая тройка — одна восьмеричная цифра.

2 → 16: то же, но группы по 4 бита.

Обратно: каждая цифра заменяется на 3 (для 8) или 4 (для 16) бита. Ведущие нули в старшем разряде можно опустить.

10110102 → 001 011 010 → 1328
10110102 → 0101 1010 → 5A16
